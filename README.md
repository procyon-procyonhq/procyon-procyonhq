## 🐾 About Procyon

**Procyon** is a Discord-first Madden CFM league management platform built to make running a franchise easier.

Instead of giving commissioners more work to manage, Procyon is designed around **automation, league management, engagement, and connected league data.**

> **Less commissioner work. More league.**
